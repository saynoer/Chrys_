# 本地 OCR 与 Office 导入

本次为 Chrys 增加图片、扫描 PDF、Excel XLSX、PPTX 导入。桌面资料库和本机知识库网页共用解析流程，识别文字继续进入清洗、分片、索引。

## 使用

1. 启动 Chrys.app 及本地知识库服务，网页刷新 http://127.0.0.1:18080/。
2. 在资料库选择文件或拖入 PNG/JPG/JPEG/WebP、PDF、XLSX、PPTX。
3. 等待本地解析完成；在原文编辑中核对识别结果、修正错误。
4. 启用对应回答模式，选择本地 RAG，建立/更新索引；先用检索测试核对召回原文。

图片与扫描页支持中英文印刷文字。本次资源已准备，识别不上传文件到云端；回答阶段若使用 DeepSeek 等云端服务，相关片段仍会按原设置发送。

PDF 仅对无有效文字的页面 OCR，不自动补识别有文字页面中的每张图片。Excel 保留工作表、行号和单元格坐标，公式只读缓存，不执行宏或公式。PPT 按页提取正文、备注及支持的嵌入位图文字，不读取外链图片。旧 XLS/PPT 需先转换；Excel 中的图片、图表和完整视觉排版不在本次范围。

## 限制

单文件30MB；PDF/PPT最多150页，PPT最多150张识别图片；图片最多2000万像素且单边不超过16000。Office解压单条5MB、合计80MB、最多3000条目；Excel最多10万单元格。单次解析180秒，超时请拆分。桌面正文最多20万字符，网页独立知识库最多200万字符。OCR可能识别错字、空格和数字，应以原文件核对。

## 本机新增内容与移除

- 独立桌面依赖：chrys/node_modules/；已解除原先指向上游的依赖链接，上游目录不变。
- OCR资源：chrys/resources/ocr/，中英文压缩语言文件合计31,082,817字节，含SHA256与来源清单及Apache许可。关闭识别任务后可删除，运行 npm --prefix chrys run setup:ocr 恢复。
- 打包应用资源：outputs/Chrys.app/Contents/Resources/ocr/；原应用备份 outputs/Chrys-before-ocr.app。
- 解析临时目录：系统临时目录内 chrys-import-*，完成、失败、超时后由程序清理。
- 安装辅助工具：work/npm-runtime/；测试素材/日志位于work/document-*，均不上传GitHub。
- 未变更现有文档、向量集合、模型或API密钥。无需更换向量模型或清空重建全部数据；新导入资料正常建立索引即可。
