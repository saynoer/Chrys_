# Chrys

维护者与二次开发作者：**will**。

屏幕理解、对话辅助、本地RAG与多项目知识库管理。

## 目录

- `shiping-rag/`：桌面应用源码与测试。
- `local-rag/`：本地向量服务管理、知识库网页、接口与测试。
- `docs/`：使用和接入说明。

## 开发

在 `shiping-rag` 内运行 `npm ci`、`npm test`、`npm run build`。本地管理网页访问 http://127.0.0.1:18080 ，仅本机使用。具体运行环境准备见 `local-rag/README.md`。

仓库不包含API密钥、账户设置、原始资料、向量数据库、模型、运行环境、日志或应用安装包。克隆后需单独准备运行环境、导入资料并建立索引。
