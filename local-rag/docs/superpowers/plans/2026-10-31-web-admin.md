# 本机知识库管理网页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 本机网页维护多个RAG项目的原始资料、分片、索引与检索，并安全接入已有识屏知识库。

**Architecture:** 独立Node HTTP服务与静态网页；托管项目使用原子JSON资料库及现有RagIndex；识屏适配器调用桌面回环鉴权桥接，所有资料变更仍走桌面队列。复用已有模型与Chroma，不迁移已有资料。

**Tech Stack:** Node 24、TypeScript、现有esbuild/unpdf/mammoth依赖、原生HTML/CSS/JS、Python生命周期脚本。

**Spec:** `docs/superpowers/specs/2026-10-31-web-admin-design.md`

## Global Constraints

- 网页仅127.0.0.1:18080，不部署公网、不注册开机任务。
- 不改上游原副本、正式版、API配置、用户原始课程内容；只在专用试用版加桥接。
- 删除进入回收站；未托管Chroma集合只读；旧v1集合不写。
- 上传30MiB、正文2,000,000字符、备份JSON45MiB；版本冲突409；写操作校验Host/Origin/CSRF。
- 复用structure-v2、bge-m3、BM25/RRF；不增加模型或付费请求。

## Review Focus

- 原文/元数据版本在网页与桌面并发编辑时不可覆盖；冲突必须拒绝并提示刷新。
- 删除、恢复与索引失败时不可返回旧版本内容，备份恢复不得覆盖已有资料。
- 恶意文件名、软链接、伪Host/Origin、跨站请求、HTML正文不得逃逸目录或读到令牌。
- 索引大任务不能阻塞状态轮询，外部集合不可被项目CRUD误删。
- 桌面关闭/桥接令牌过期时清楚报未连接，不在后台私自写识屏数据。
